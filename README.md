# Position Size Calculator & Risk Dashboard

A free, browser-based position size calculator and portfolio risk dashboard for traders.

**Live Demo:** https://timoranjes.github.io/position-size-calculator/

## Features

### Position Size Calculator
- **Stocks**: Calculate optimal share count based on account size, risk %, entry, and stop
- **Forex**: Standard lot sizing for USD-quote pairs
- **Crypto**: Position sizing for volatile crypto assets
- Risk/Reward ratio calculation
- Potential profit estimation

### Portfolio Risk Dashboard
- Add multiple positions with ticker, shares, entry, and stop
- Visual risk allocation bar chart
- Concentration risk detection
- Portfolio-level risk percentage
- Smart alerts for over-exposure

### Risk Guide
- The 1% rule explained
- Position sizing formula walkthrough
- Why position sizing matters more than entry timing

## Tech Stack
- Vanilla HTML/CSS/JS — zero dependencies
- Deployed on GitHub Pages
- No backend, no database, no sign-up
